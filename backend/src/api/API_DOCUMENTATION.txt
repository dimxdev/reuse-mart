## AUTH REST API
 1. http://localhost:3000/auth/register/customer (POST, semua bisa akses, register customer)
 2. http://localhost:3000/auth/register/admin (POST, [owner] role, register admin)
 3. http://localhost:3000/auth/register/owner673245 (POST, register owner)
 4. http://localhost:3000/auth/login (login) (POST, semua bisa akses, login)
 5. http://localhost:3000/auth/delete/admin/:adminId (DELETE, [owner] role, menghapus admin berdasarkan id)
 6. http://localhost:3000/auth/admin (GET, [owner] role, mengambil semua data admin)

## PRODUCT REST API 
 7. http://localhost:3000/product (GET, semua bisa akses, mengambil semua data product)
 8. http://localhost:3000/product/:productId (GET, semua bisa akses, mengambil data product berdasarkan id)
 9. http://localhost:3000/product (POST, [admin, owner] role, create product baru)
 10. http://localhost:3000/product/:productId (PATCH, [admin] role, edit data product)
 11. http://localhost:3000/product/:productId (DELETE, [admin] role, hapus product)

## CATEGORY REST API 
 12. http://localhost:3000/category (GET, semua bisa akses, mengambil semua data category)
 13. http://localhost:3000/category/:categoryId (GET, semua bisa akses, mengambil data category berdasarkan id)
 14. http://localhost:3000/category (POST, [admin] role, create category baru)
 15. http://localhost:3000/category/:categoryId (PATCH, [admin] role, edit data category)
 16. http://localhost:3000/category (DELETE, [admin] role, delete data category)

## CART REST API 
 17. http://localhost:3000/cart (GET, [customer] role, mengambil semua data cart customer)
 18. http://localhost:3000/cart (POST, [customer] role, membuat/insert data cart baru)
 19. http://localhost:3000/cart/:cartId (PATCH, [customer] role, edit jumlah product di dalam cart)
 20. http://localhost:3000/cart/:cartId (DELETE, [customer] role, menghapus cart berdasarkan id)
 21. http://localhost:3000/cart (DELETE, [customer] role, menghapus semua isi cart)

## ORDER REST API 
 22. http://localhost:3000/order (POST, [customer] role, checkout semua isi cart)
 23. http://localhost:3000/order/my-order (GET, [customer] role, mendapatkan semua riwayat transaksi)
 24. http://localhost:3000/order/ (GET, [admin, owner] role, mendapatkan semua data transaksi customer)
 25. http://localhost:3000/order/:orderId (GET, [customer, admin, owner] role, mendapatkan data detail order berdasarkan id order)
 26. http://localhost:3000/order/status/:orderId (PATCH, [admin] role, mengubah status pengiriman barang)
 27. http://localhost:3000/order/dikemas (GET, [admin] role, mendapatkan semua data transaksi customer yg sedang dikemas)
 28. http://localhost:3000/order/dikirim (GET, [admin] role, mendapatkan semua data transaksi customer yg sedang dikirim)

## DASHBOARD SUMMARY REST API
 29. http://localhost:3000/dashboard/summary (GET, [admin, owner] role, mengambil semua data summary dashboard)

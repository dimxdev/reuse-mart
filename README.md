# 🛒 ReuseMart

**ReuseMart** adalah aplikasi web e-commerce bertema vintage untuk jual beli barang bekas dengan tampilan elegan dan sederhana.  
Dibangun menggunakan **React.js**, **Express.js**, dan **MySQL**, serta menyediakan akses berbasis peran untuk **Customer**, **Admin**, dan **Owner**.

---

## 🌿 Tentang Proyek

ReuseMart bertujuan untuk mendukung gaya hidup berkelanjutan dengan menyediakan platform jual beli barang bekas berkualitas.  
Dengan nuansa **Warm Vintage**, pengguna dapat menikmati pengalaman berbelanja yang hangat dan nyaman sekaligus mendukung budaya ramah lingkungan.

---

## 🚀 Fitur

### 👤 Customer
- Registrasi dan login ke sistem  
- Menelusuri dan membeli produk bekas  
- Checkout menggunakan **pembayaran QRIS**  
- Memasukkan nama dan alamat pengiriman saat checkout  
- Melacak status pesanan: *Dikemas*, *Dikirim*, *Sampai*  
- Melihat riwayat transaksi  

### 🧰 Admin
- Login ke dashboard admin  
- Menambah, mengedit, dan menghapus produk  
- Mengelola kategori produk  
- Memperbarui status pesanan  
- Melihat laporan penjualan  

### 👔 Owner
- Login ke dashboard owner  
- Melihat analisis penjualan secara keseluruhan  
- Mengelola akun admin  
- Membuat dan mengekspor laporan

## 🧩 Teknologi yang Digunakan

| Lapisan | Teknologi |
|----------|------------|
| Frontend | React.js + TailwindCSS + Framer Motion |
| Backend | Express.js (Node.js) |
| Database | MySQL |
| ORM | Prisma |
| Simulasi Pembayaran | QRIS |

## 💻 Instalasi

```bash
# Clone repository
git clone https://github.com/yourusername/reuse-mart.git
cd reuse-mart

# Install dependencies
npm install

# Jalankan server backend
cd backend
npm start

# Jalankan frontend
cd frontend
npm run dev
```

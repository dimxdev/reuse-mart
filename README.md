# 🛒 ReuseMart

**ReuseMart** is a vintage-themed e-commerce web application for buying and selling secondhand goods with an elegant and simple interface.  
Built using **React.js**, **Express.js**, and **MySQL**, it provides role-based access for **Customers**, **Admins**, and **Owners**.

---

## 🌿 About the Project

ReuseMart aims to promote sustainability by providing a platform for high-quality used items.  
With a **Warm Vintage** aesthetic, users can enjoy a cozy shopping experience while supporting eco-friendly reuse culture.

---

## 🚀 Features

### 👤 Customer
- Register and login to the system  
- Browse and buy used products  
- Checkout using **QRIS payment**  
- Enter name & shipping address during checkout  
- Track order status: *Dikemas*, *Dikirim*, *Sampai*  
- View transaction history  

### 🧰 Admin
- Login to admin dashboard  
- Add, edit, and delete products  
- Manage product categories  
- Update order status  
- View sales reports  

### 👔 Owner
- Login to owner dashboard  
- View overall sales analytics  
- Manage admin accounts  
- Generate and export reports  

---

## 🧩 Tech Stack

| Layer | Technology |
|-------|-------------|
| Frontend | React.js + TailwindCSS + Framer Motion |
| Backend | Express.js (Node.js) |
| Database | MySQL |
| Payment Simulation | QRIS |
| Theme | Warm Vintage (Earthy tones, soft shadows, smooth animations) |

## 💻 Installation

```bash
# Clone repository
git clone https://github.com/yourusername/reuse-mart.git
cd reuse-mart

# Install dependencies
npm install

# Start backend server
cd backend
npm start

# Start frontend
cd frontend
npm run dev
```
